# 微信防撤回 · Windows 版（测试版）

> **测试版：还没有在真实的 Windows 微信上验证过。** 目前只做过静态核对、单元测试，以及在测试环境里直接执行打过补丁的代码。
> 请用**小号**试，并先看[风险](#风险)。

别人撤回的消息原样留住，并在它下面告诉你撤回的是什么、隔了多久：

| 对方撤回了 | 你看到的提示 |
|---|---|
| 文字 | "张三" 撤回了一条消息：「晚上八点开会」（发出 1 分 15 秒后） |
| 表情包、图片、语音、视频 | "张三" 撤回了一个表情包（发出 10 秒后） |
| 文件、链接 | "张三" 撤回了一个文件：「报价单.xlsx」（发出 2 分钟后） |

你自己撤回的消息照常撤回（按提示文字判断，只保证简体中文界面）。运行时不写盘、不联网，不改网络协议、不自动化。

## 能不能用

| 要求 | 说明 |
|---|---|
| 系统 | 64 位 Windows 10 / 11 |
| 微信 | **4.2.0.53**（只支持列出的版本，见 `patches/`） |
| 其他 | 不需要装任何东西，用系统自带的 PowerShell |

版本号在安装目录里就能看到，例如 `C:\Program Files\Tencent\Weixin\4.2.0.53\`。

## 安装

1. 下载本仓库（**Code → Download ZIP**，解压；或 `git clone`）。
2. 打开 `windows` 文件夹，双击 **`install.cmd`**。想先检查，就在命令行里运行：

   ```
   install.cmd -Check
   ```

3. 安装前要**完全退出微信**：在任务栏托盘图标上点右键退出，只关窗口不算。
4. 弹出管理员权限窗口时点「是」。看到「安装完成」后打开微信。
5. 让别人**新发一条**消息，等十几秒再撤回，看提示。

微信装在别的位置：

```
install.cmd -Path "D:\Tencent\Weixin"
```

## 还原

退出微信，双击 **`uninstall.cmd`**。会把 `Weixin.dll` 变回官方原文件，并核对校验和。

安装时会在 `C:\ProgramData\WeChatAntiRecall\` 留一份约 200 MB 的备份，还原后不会自动删除，不需要了可以手动删。
正常还原用不到它；`Weixin.dll` 被杀毒软件删掉或被改坏时，`uninstall.cmd` 会用它放回。

## 常见问题

**提示「没有支持的版本」**
补丁只认特定版本的原文件。版本号一样却不支持，说明 `Weixin.dll` 被别的工具改过，请先用那个工具还原，或重装微信。

**杀毒软件报警、拦截或删除文件**
因为改了微信的程序文件。是否放行由你决定；不放心就不要用。被删除的文件可以从备份恢复，或重装微信。

**「Windows 已保护你的电脑」**
下载的脚本会被 SmartScreen 提示。内容都是明文，可以先用记事本打开看。

**Windows 11 打不开微信，提示被「智能应用控制」阻止**
它可能会拦截签名失效的程序文件。本工具不会、也不建议你为此关闭它；运行 `uninstall.cmd` 还原即可。

**装好了但没效果**
安装目录里有多个版本文件夹时，微信实际运行的可能是另一个。安装时会提醒。

**微信打不开或崩溃**
运行 `uninstall.cmd` 还原，然后把现象反馈到 [Issues](https://github.com/stargif/wechat-antirecall/issues)。

**微信更新后失效**
正常现象，更新会换成新版本的文件夹。新版本支持后再装一次。

**提示里没有内容，只有「撤回了一条消息」**
只认得**本次启动微信之后**收到或加载过的消息（最多记住最近 4096 条）。

## 风险

**有被限制账号的可能，没有人能保证不会。请自行判断，风险由使用者承担。**

- 非官方、未经授权的修改违反微信的使用规范，可能被限制功能或封禁。
- 本工具修改 `Weixin.dll`，文件的数字签名会失效，可以被检测到。**不做任何躲避检测的手段。**
- 建议只用小号，不要和其他修改微信的工具混用。

## 原理

微信收到撤回通知后，会解析出「删哪条（`newmsgid`）」和「提示文案」。补丁只改两处指令，跳到新增的一小段代码：

| 位置（4.2.0.53） | 作用 |
|---|---|
| `0xA8B286` 消息终结器收尾 | 记下「服务器 ID → 类型 + 摘要」；是撤回通知就把提示排到原消息下面 |
| `0x22E38B9` 撤回解析成功 | 查到原消息就改写提示，并把 `newmsgid` 清零，让消息留住 |

新增代码放在两个新的节里：`.wxar`（代码，约 9 KB）和 `.wxad`（内存缓存，约 1.8 MB，不占文件）。它不依赖任何库、没有重定位、
不分配内存；改写提示时够放就原地写，放不下才调用微信自己的 `std::string` 赋值函数。自己撤回的不拦、不改。

安装脚本先核对原文件的 SHA-256，再核对每一处原始字节，最后核对结果的 SHA-256，任何一步对不上都不动。

## 给开发者

```
install.ps1 / uninstall.ps1   安装、还原（install.cmd / uninstall.cmd 是双击用的入口）
patches/<版本>.json           补丁：原文件与结果的 SHA-256、改动、追加的内容
runtime/tip.c                 新增代码的源码
runtime/test_tip.c            单元测试（任意平台）
tools/build.py                从官方 Weixin.dll 生成补丁
tools/e2e.c                   端到端测试（Apple Silicon 的 Mac 上用 Rosetta 执行打过补丁的代码）
tools/test_install.ps1        安装脚本的测试（CI 会跑）
```

```
clang -std=c11 -DWXAR_TEST runtime/test_tip.c -o test_tip && ./test_tip
```

定位方法：`Weixin.dll` 里 `replacemsg` 等字符串是明文，引用它的函数就是撤回解析；它所在类的虚函数由消息终结器调用。
适配新版本时更新 `tools/build.py` 里的 `TARGET` 和 `runtime/tip.c` 开头的布局。
